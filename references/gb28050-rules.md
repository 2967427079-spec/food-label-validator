# GB 28050 营养标签规则速查

## 能量换算系数 (kJ/g)
- 蛋白质 17, 脂肪 37, 碳水化合物 17, 膳食纤维 8, 乙醇 29, 有机酸 13
- 能量守恒容差: ±20%（考虑纤维/糖醇及修约差异）

## "0" 界限值（每 100 g / 100 mL）
- 能量 ≤ 17 kJ；脂肪 ≤ 0.5 g；糖 ≤ 0.5 g；碳水化合物 ≤ 0.5 g（标 0 时）
- 反式脂肪酸 ≤ 0.3 g；钠 ≤ 5 mg；蛋白质 ≤ 0.5 g（标 0 时）

## NRV（营养参考值，成人）
- 能量 8400 kJ；蛋白质 60 g；脂肪 60 g；碳水化合物 300 g；钠 2000 mg

## 常见营养声称条件（附录 C，固体 / 液体）
- 高蛋白: ≥ 12 g/100 g（≥ 6 g/100 mL）
- 低脂: ≤ 3 g/100 g（≤ 1.5 g/100 mL）
- 脱脂: ≤ 0.5 g/100 g(mL)
- 无糖: ≤ 0.5 g/100 g(mL)
- 低糖: ≤ 5 g/100 g（≤ 2.5 g/100 mL）
- 高钙: ≥ 240 mg/100 g（≥ 120 mg/100 mL），即 ≥ 30% NRV
- 低钠: ≤ 120 mg/100 g(mL)

## 强制标示
能量 + 蛋白质、脂肪、碳水化合物、钠（"1+4"），及对应 NRV%。

## 修约与容差
- 标示值允许误差: 能量/脂肪/钠 ≤ 120% 标示值；蛋白质/碳水 ≥ 80% 标示值（监督抽查口径）。
- 单位: 能量 kJ，宏量营养素 g，钠 mg。注意 mg/g 误读是 OCR 常见错误。
