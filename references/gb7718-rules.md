# GB 7718 配料表规则速查

## 核心规则：降序排列
各种配料按制造或加工时**加入量的递减顺序**排列（加入量 ≤ 2% 的配料可不按序）。
→ 这是交叉验证的基石：排位靠前的配料必须在该食品的宏量营养素谱中占主导。

## 标示要求
- 配料表标题为"配料"或"配料表"；复合配料需展开原始配料（有国标且添加量 <25% 可豁免）。
- 食品添加剂标示通用名称（可括号内标功能类别 + 具体名称/INS 号）。
- 水、食用香精香料需标示；加工中挥发的水可不标。
- 致敏物质（麸质、甲壳类、蛋、鱼、花生、大豆、乳、坚果）推荐提示标示。

## 与营养表联动的关键推断
- 第一位是植物油/起酥油/人造奶油 → 脂肪应为主要营养素。
- 前三位含白砂糖/果葡糖浆/麦芽糖浆 → 碳水化合物（糖）应显著。
- 含乳粉/大豆蛋白/坚果 → 蛋白质不应接近 0。
- 含食盐、酱油、味精（谷氨酸钠）→ 钠不应接近 0。
- 含氢化/部分氢化植物油 → 应标示反式脂肪酸（GB 28050 要求）。
